# Merve Usta’nın Yufka Şenliği

GitHub Pages ile yayınlanabilir oyun projesi.

## Dosya yapısı
- `index.html`: Ana sayfa
- `assets/`: Oyunda kullanılan 25 görsel
- `css/style.css`: Görünüm ve stiller
- `js/game.js`: Oyun kodu

## GitHub Pages
Depo ayarlarında **Pages** bölümünden yayın kaynağı olarak `main` dalını ve `/ (root)` klasörünü seçin.
